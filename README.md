# Learning OOPS

A collection of my Object-Oriented Programming practice programs and notes in C++.

## Topics Covered

- Classes and Objects
- Constructors and Destructors
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Function Overloading and Overriding
- Operator Overloading
- Virtual Functions
- Exception Handling
- File Handling

## Purpose

This repository tracks my progress while learning OOPS concepts through small programs, examples, and practice problems.

## Structure

Each topic is organized into its own folder so that programs can be revisited and practiced independently.

> Learning by writing, testing, and improving one program at a time.
